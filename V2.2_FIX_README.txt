NordHome v2.2 — виправлення постійних налаштувань

Що виправлено:
- PostgreSQL / Supabase автоматично читається з C:\Users\<користувач>\.nordhome\.env
- Нова пошта та Telegram читаються з того самого постійного конфігу
- локальний .env більше не є обов'язковим
- парсер конфігурації коректно працює з URL/паролями, що містять = або #
- додана безпечна перевірка без показу секретів: npm run config:check

Пріоритет конфігурації:
1. змінні середовища Windows/хостингу
2. .env у папці проєкту
3. C:\Users\<користувач>\.nordhome\.env

Швидкий запуск:
1. npm install
2. npm run config:check
3. npm run dev

Команда config:check показує лише OK/NO і НІКОЛИ не друкує значення ключів.
