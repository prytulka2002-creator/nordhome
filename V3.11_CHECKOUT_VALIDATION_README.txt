NordHome v3.11 — Checkout Validation

Що додано:
- перевірка імені та прізвища;
- перевірка українського номера телефону (0XXXXXXXXX або +380XXXXXXXXX);
- перевірка email, якщо він введений;
- населений пункт обов'язково має бути обраний зі списку;
- перевірка служби доставки та способу отримання;
- для Нової пошти відділення/поштомат має бути обраний із живого списку;
- для кур'єра перевіряється адреса;
- перевірка способу оплати;
- коментар обмежено 600 символами;
- помилки показуються безпосередньо біля проблемних полів;
- сервер повторно перевіряє критичні дані, тому клієнтську перевірку не можна обійти простим POST-запитом.

Міграція бази даних не потрібна.
Після розпакування: npm install, потім npm run dev.
