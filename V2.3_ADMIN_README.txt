NordHome v2.3 — повна адмін-панель

Що додано:
- Dashboard: виручка, замовлення, клієнти, товари, склад, малий залишок
- Замовлення зі статусами
- Товари + SKU/артикул + залишок
- Клієнти, автоматично зібрані із замовлень
- Окремий розділ «Залишки» для швидкої зміни кількості
- Налаштування магазину в PostgreSQL
- PostgreSQL/Supabase залишається основним сховищем
- Постійний конфіг з C:\Users\<USER>\.nordhome\.env підтримується

ВАЖЛИВО ПРИ ПЕРШОМУ ЗАПУСКУ v2.3:
1. npm install
2. npm run config:check
3. npm run db:setup
4. npm run dev

Команда db:setup НЕ видаляє старі товари/замовлення. Вона лише додає нові поля stock, sku та таблицю store_settings.
