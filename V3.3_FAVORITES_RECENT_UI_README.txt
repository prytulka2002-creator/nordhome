NordHome v3.3 — Обране на картках + Нещодавно переглянуті

Що змінено:
- Сердечко тепер відображається на кожній картці товару в каталозі та на головній.
- Натискання на сердечко додає/видаляє товар з Обраного без переходу на сторінку товару.
- Лічильник Обраного у шапці оновлюється автоматично.
- У шапці додана окрема кнопка з годинником для Нещодавно переглянутих.
- Лічильник показує кількість переглянутих товарів.
- Сторінка /recent показує останні 12 переглянутих товарів та дозволяє очистити історію.
- Сердечка працюють також у блоці схожих товарів та на сторінці Обране/Нещодавно.
- Дані зберігаються у localStorage.
- База даних не змінюється, db:setup запускати не потрібно.

Запуск:
1) npm install
2) npm run dev
