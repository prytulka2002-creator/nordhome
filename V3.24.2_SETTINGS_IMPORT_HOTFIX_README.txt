NordHome v3.24.2 — Settings Import Hotfix

Виправлено перенесення налаштувань у White Label:
- імпорт запускається окремою кнопкою та прихованим file input;
- результат імпорту показується прямо під кнопками, без потреби прокручувати форму вниз;
- перевіряється розмір файлу (до 500 КБ), JSON і структура settings;
- після імпорту налаштування повторно читаються із сервера, щоб підтвердити збереження;
- явні стани: перевірка / успіх / помилка;
- експорт також показує видимий результат;
- захист від масивів та некоректного JSON на сервері.

База даних: міграція не потрібна.
