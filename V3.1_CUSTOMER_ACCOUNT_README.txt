NordHome v3.1 — особистий кабінет покупця

Що змінилось:
- Видиму кнопку «Вхід для адміністратора» повністю прибрано з клієнтського сайту.
- /admin залишається робочим напряму.
- У шапці додано «Кабінет».
- Реєстрація покупця: ім'я, прізвище, телефон, email, пароль.
- Вхід по телефону або email + пароль.
- Паролі зберігаються як scrypt-хеші, не відкритим текстом.
- Сесія покупця зберігається в PostgreSQL до 30 днів, тому перезапуск сервера її не скидає.
- Кабінет автоматично показує старі та нові замовлення з тим самим телефоном/email.
- Історія замовлень зі статусом, датою, сумою і товарами.
- «Повторити» переносить доступні товари з минулого замовлення у кошик з актуальною ціною/наявністю.
- Можна редагувати ім'я, прізвище та email.

Після оновлення ОБОВ'ЯЗКОВО:
  npm install
  npm run config:check
  npm run db:setup
  npm run dev

Нові таблиці PostgreSQL:
- customers
- customer_sessions

Старі товари та замовлення не видаляються.
