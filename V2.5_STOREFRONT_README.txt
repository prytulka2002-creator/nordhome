NordHome v2.5

Додано:
- окремі URL категорій /category/...
- фільтр за матеріалом
- фільтр за кольором
- вкладки Новинки / Хіти / Акції
- акційна та стара ціна
- бейджі Новинка / Хіт / Знижка
- сортування за найбільшою знижкою
- категорії на головній відкривають свою сторінку

Базу даних оновлювати не потрібно. Поточні позначки акцій/хітів/новинок для демо-товарів задаються у storefront-коді. Наступний етап може перенести ці поля в PostgreSQL та адмінку, щоб ними керувати вручну.
