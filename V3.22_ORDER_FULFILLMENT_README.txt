NordHome v3.22 — Advanced Order Fulfillment

Що додано одним пакетом:
- ТТН для кожного замовлення.
- Окрема служба доставки для фактичного відправлення.
- Статус доставки: очікує, готується, передано перевізнику, в дорозі, прибуло, отримано, повернення.
- Швидкий пошук в адмінці за номером замовлення, ПІБ, телефоном, email, ТТН, містом і службою доставки.
- Фільтри за статусом замовлення, службою доставки та статусом доставки.
- Редактор відправлення прямо всередині картки замовлення.
- Відображення ТТН, служби та статусу доставки клієнту у /track-order.
- Відображення ТТН у кабінеті клієнта та модальному вікні статусу.

Після оновлення ОБОВ'ЯЗКОВО один раз виконайте:
  npm run db:setup

Це безпечно додає нові колонки до існуючої PostgreSQL/Supabase бази й не видаляє старі замовлення.

Потім:
  npm run build
  npm start

Версія: 3.22.0
