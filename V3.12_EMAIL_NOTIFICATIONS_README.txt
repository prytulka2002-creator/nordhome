NordHome v3.12 — Email-сповіщення клієнтам

Що додано:
- email після успішного оформлення замовлення;
- email при реальній зміні статусу в адмінці;
- статуси: підтверджено, відправлено, виконано, скасовано;
- лист містить номер замовлення, суму, доставку та товари;
- email-помилка не блокує замовлення або зміну статусу;
- якщо email клієнта не вказаний або SMTP не налаштований — лист просто пропускається;
- секрети SMTP зберігаються у постійному ~/.nordhome/.env, а не в коді.

Налаштування:
1. npm install
2. npm run email:setup
3. Введіть SMTP-параметри локально у консолі. Не надсилайте пароль/API-ключ у чат.
4. Перезапустіть npm run dev.
5. npm run config:check — Email SMTP має показати OK.

База даних: міграція не потрібна.
