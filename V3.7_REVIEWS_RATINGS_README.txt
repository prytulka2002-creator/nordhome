NordHome v3.7 — Відгуки та рейтинг

Додано:
- рейтинг 1–5 зірок;
- форма відгуку на сторінці товару;
- нові відгуки спочатку мають статус pending;
- адмінка → Відгуки: опублікувати, приховати, видалити;
- середній рейтинг і кількість відгуків на картках та сторінці товару;
- у публічний рейтинг входять лише approved-відгуки.

ВАЖЛИВО після оновлення один раз запустити:
npm run db:setup

Потім:
npm run dev
