NordHome v2.7 — inventory

1. npm install
2. npm run config:check
3. npm run db:setup   (обов'язково)
4. npm run dev

Нове:
- 3 режими наявності: Авто / Під замовлення / Немає.
- Авто: stock > 0 = в наявності; stock = 0 = немає.
- Під замовлення можна купувати при stock = 0.
- Після створення замовлення складський товар автоматично списується.
- При скасуванні замовлення списаний залишок повертається.
- При відновленні скасованого замовлення залишок резервується знову, якщо його достатньо.
- Сервер перевіряє актуальну ціну і залишок, не довіряючи даним кошика.
