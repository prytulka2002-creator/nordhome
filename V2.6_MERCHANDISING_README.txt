NordHome v2.6 — керування Новинками / Хітами / Акціями з адмінки

Що нового:
- is_new, bestseller, sale_percent, old_price зберігаються у PostgreSQL.
- У редагуванні товару є блок «Просування товару».
- Галочки «Новинка» і «Хіт продажу».
- Поля «Знижка, %» та «Стара ціна, грн».
- Каталог, картки та сторінка товару читають ці значення з БД, а не з демо-коду.
- Під час першого db:setup для старих 8 демо-товарів зберігаються бейджі з v2.5. Повторний db:setup не перезаписує ваші зміни.

Оновлення:
1) npm install
2) npm run config:check
3) npm run db:setup   <-- ОБОВ’ЯЗКОВО для v2.6
4) npm run dev

Перевірка:
- /admin -> Товари -> Редагувати
- поставте «Новинка» або «Хіт», або задайте знижку
- збережіть і відкрийте каталог
- фільтри «Новинки / Хіти / Акції» мають працювати за даними PostgreSQL
