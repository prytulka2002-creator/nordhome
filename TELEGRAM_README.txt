NORDHOME — TELEGRAM

1. Двічі натисни SETUP_TELEGRAM.bat.
2. Відкрий @BotFather у Telegram і створи бота через /newbot.
3. Встав у вікно токен від BotFather.
4. Відкрий свого нового бота, натисни START або відправ /start.
5. Повернись у чорне вікно та натисни Enter.
6. Скрипт сам знайде chat ID, збереже дані в .env і надішле тест.
7. Перезапусти NordHome: Ctrl+C, потім npm run dev.

Після цього кожне успішне замовлення буде:
- збережене у data/orders.json;
- надіслане в Telegram з номером, клієнтом, телефоном, товарами,
  сумою, способом оплати та доставкою.

ВАЖЛИВО:
- не публікуй .env;
- не надсилай нікому BOT TOKEN;
- .env уже доданий у .gitignore.
